OCTO AI GAME AGENT
Library assistant
Changes need your approval

                
Ask Octo AI to investigate code issues or register a game whose files are already in the repository. It prepares a change for your review; only approval opens a GitHub pull request. It never merges or deploys changes.

                
Try “Which games need attention?” or “Review the game hub code and propose a fix for [issue].”

GitHub proposal creation is not configured. A maintainer can enable it in Supabase function secrets. Approved proposals open a pull request for review.
