How to Install Mods (Beginner's Guide)

1. Where to download mods?

We recommend GameModding.com or GTAinside.

⚠️ IMPORTANT: DO NOT use "Auto-Installers" (.exe files). Always look for the "Manual Download" or "ZIP Archive" button. You need to extract the ZIP file to get the raw mod files.

2. ✅ What IS supported?

Any mod that replaces existing game assets by modifying the models/gta3.img file can be installed here. This includes:

  • Vehicles, Weapons, Peds, Buildings: Upload the .dff (3D Model) and/or .txd (Textures) files.
  • Simple Player Skins: Upload the skins in .bmp format.

3. ❌ What is NOT supported?

  • CLEO / Scripts: Anything that modifies game logic or adds new features (e.g., trainers, CLEO scripts).
  • Graphics Mods (ENB): Files like d3d8.dll or enbseries.ini.
  • Screens/Menus: Any type of replacement outside models/gta3.img file (e.g., hud.txd or intro.txd).
  • Handling/Physics: Modifying handling.cfg or default.ide. (Your custom car will drive like the car it replaced).

Special Note: Changing Claude's Character (e.g. custom skins / models)

If you download a mod to replace Claude, it will usually have a player.dff and player.txd. To make it work:

  1. Upload the player.dff here.
  2. You must extract the character's image from the player.txd file using a PC tool like TXD Workshop, and save it as a .bmp file.
  3. Upload that image file here.
  4. Start the game, press ESC -> Options -> Player Setup, and select your new skin!

Mods are injected safely into RAM. If a mod breaks your game, just click "Uninstall" and refresh the page!
